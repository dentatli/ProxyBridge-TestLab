Сборки

Выберите файлы установленного ProxyBridge. Проверка читает файлы, не запускает программу и не меняет драйвер.

Технические сведения

      

        
Сохранённые сборки

        
Выбор повторно проверит файлы. Собственное имя не подтверждает совместимость новой сборки.

Выбранные тесты выполняются последовательно. При ошибке очередь останавливается. Остановка дожидается текущего прогона и очистки, остальные тесты не запускаются.

      
Длительность и нагрузка задаются отдельно для каждого теста.

      
В каждом режиме используется контролируемый получатель. Прямой трафик служит базой для сравнения выбранного пути через SOCKS5.
