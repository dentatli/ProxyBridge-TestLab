# ProxyBridge TestLab — «На этом ПК»

1. Запустите `Start.cmd` и подтвердите запрос Windows на права администратора.
2. В разделе «Сборки» нажмите «Найти установленный ProxyBridge» и выберите найденный комплект. Для нестандартной установки можно указать папку вручную. Типы: «Driver WFP» и «WinDivert». Для WinDivert поддержка заявлена только для версии 4.3.0; поддержка остальных версий не заявлена. Номер версии определяется отдельно от типа; старые сохранённые выборы сохраняют свои идентификаторы.
3. Откройте «Тестирование» → «На этом ПК». Выберите одну из десяти проверок, полноту, длительность и нагрузку. «Этапы и точный выбор» раскрывает внутренние сценарии.
4. Откройте «Запуск». Остановка выполняется кнопкой в приложении; дождитесь результата очистки. Общий статус и подробности этапов доступны в «Результатах».

Для первого короткого запуска подходит TCP → Базовая → Быстро → Низкая: три этапа, оценка около 1,3 минуты. Это оценка времени с подготовкой, а не гарантированный предел. Наборы свыше пяти минут требуют отдельного подтверждения.

В комплекте есть .NET и Python 3.11 с зависимостями. Отдельная установка Python, Ubuntu или настройка SSH для локального режима не нужна. ProxyBridge устанавливается пользователем отдельно. TestLab не устанавливает продуктовый драйвер и не меняет системные параметры подписи или доверия.

Проверка файлов установки не означает подтверждения совместимости или успешного прохождения сетевых сценариев. Ошибки продукта, маршрута и очистки сохраняются как ошибки. Неподтверждённые измерения не становятся PASS.

Сохранённые наборы импортируются и экспортируются в прежнем формате с атомарными ID. Если наборы были сохранены в браузере на другом порту, экспортируйте их там и импортируйте в этом приложении. История попыток хранится в `%LOCALAPPDATA%\ProxyBridge-TestLab\traffic-lab`; настройки выбора файлов защищены Windows DPAPI.

`packaging\Repair-ProxyBridge-TestLab.ps1` проверяет комплект по SHA256SUMS.txt. `packaging\Stop-ProxyBridge-TestLab.ps1` завершает только этот экземпляр после окончания проверок; активную проверку сначала остановите в интерфейсе. Если порт 5178 занят другим пакетом, завершите тот экземпляр перед запуском.

Короткая проверка установленного Driver WFP: TCP RTT/отправка/получение прошли; UDP connected остановлен на контроле UNRULED, следующий UDP-этап пропущен. Отмена TCP и очистка подтверждены. Это не приёмка всех 51 сценария, HIGH или длительных прогонов. При переключении типов необходима подтверждённая очистка; чужие процессы и службы приложение не завершает. Удалённый режим в рамках этого выпуска не дорабатывался.
