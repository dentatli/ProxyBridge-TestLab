# C# transport engine — перенос в работе

Выбор по запросу пользователя: C# для всего измеряющего транспортного тракта (генератор TCP/UDP, приёмник, SOCKS5); существующие прикладные библиотеки пока сохраняются. Пользователь спросил, какой объём лучше; рекомендован этот вариант, дополнительное подтверждение не требуется. Продуктовые источники и диагностика драйвера не входят в scope. Полный прогон обеих сборок пользователь запустит после готовности новой версии.

## Готово в исходниках, ещё не включено в приложении

- src/ProxyBridge.TestLab.TrafficEngine: .NET10 Windows console host, роли origin/relay и worker-only; без новых NuGet-зависимостей. Чистый managed C#, async sockets, отдельный read buffer для duplex. Native processes должны быть отдельными от Python controller/адаптеров и друг от друга.
- Совместимый контролируемый TCP wire: challenge/HMAC, flow/run, sequence/pattern/byte counters/SHA256, echo/hold/upload/download/duplex/churn. Ошибка duplex отменяет вторую сторону, оба результата наблюдаются.
- UDP: тот же подписанный JSON+payload, source/run/flow/payload/MAC guards, bounded pending/replay/2s deadlines, подключённые и неподключённые сокеты, честные sent/received/loss/achieved rate. Неверный пакет не рушит общий origin. 4MiB shared origin buffer; отдельные ingress/egress sockets каждой SOCKS-association с256KiB buffers.
- SOCKS5: обязательная авторизация, только точный разрешённый loopback origin/порты, собственный relay endpoint на ассоциацию; TCP/UDP route fingerprints и counters по всем потокам. Прикладной TCP передаётся без synthetic preface, привязывается после authenticated origin callback. QUIC v1/CID учёт с общим bounded budget, подтверждается расшифрованным origin, не по догадке о трафике.
- Private loopback control: HMAC поверх сырых envelope bytes, nonce/recent replay guard, deadlines/size/concurrency limits; не продуктовая route evidence сам по себе. Resource/worker PID identity проверяется, замена PID отвергается до отправки нагрузки. Worker jobs active и socket lifetimes дают дополнительный idle gate; global socket count уменьшается после dispose.
- src/trafficlab/native_engine.py: authenticated IPC, dispatch, protocol callbacks, суммирование CPU/private commit/RSS отдельных origin+adapter процессов (RSS не уникальная память ПК). Conditional hooks в agent/local_runtime/worker/schedule/session_runner. Старый путь без native fields остаётся прежним. Native branch только local.
- tests/engine/verify_transport.py — один необходимый contract gate, без ProxyBridge/драйверов/system changes; независимые Python peers, native pipeline, источник/подпись/данные, отмена/очистка/PID/replay. Не UI автотесты и не product acceptance.
