## Запуск пользователем

Закончить/остановить текущие тесты; не запускать вручную другой ProxyBridge одновременно. В PowerShell администратора:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\src\ProxyBridge-TestLab\scripts\Invoke-LocalTcpThreeModes.ps1" -Phase Run
```

Около 3–5 минут, три коротких прогона. Новый каталог создаётся автоматически в artifacts/local-route/tcp-rtt-three-modes-smoke-*. Итоговый summary.md содержит RTT трёх путей, CLI CPU/RAM UNRULED и PROXY, разницы UNRULED−OFF/PROXY−OFF/PROXY−UNRULED. Если скрипт требует перезагрузку или даёт ошибку, сохранить точный вывод и не повторять автоматически. В следующем сообщении передать вывод/каталог.

pb_tcp_three_mode_report.py повторно проверяет исходные per-run verdicts и соответствие конфигурации/комплекта/driver inventory/GUID. Ошибки/неполные серии не дают сравнительную таблицу с подтверждёнными значениями. Реальный первый запуск проверяет новую интеграцию; он не является бессмысленным повторением успешных старых серий.

После результата обновлённый UI нужно пересобрать/перезапустить вручную штатным dotnet run и CtrlF5 (агент build не выполняет). Results → «Задержка TCP: выключен / без правила / SOCKS5». Хранится отдельная история/последняя попытка по этому сценарию; нет подстановки двухрежимных показателей в новую серию. Строгая basename GET проекция читает только сохранённые отчёты; запуск новой серии пока только указанной командой, автоматическая GUI кнопка ещё не подключена. Старые frozen GUI планы потребуют нового «Подготовить запуск» после изменения SHA существующего контроллера.

## Ограничения

Один фиксированный порядок и 128 измерений — проверка готовности. Разница может зависеть от фоновой нагрузки/прогрева/порядка; не объявлять выигрыш или универсальные накладные расходы продукта. PROXY включает весь SOCKS5-путь/стенд, CPU CLI не выделяет kernel driver CPU/RAM/ватты. Не ICMP ping/время открытия соединения/предел скорости/игровая или длительная стабильность. Следующий этап после user подтверждения — повторные чередующиеся режимы и интеграция выбора набора; затем отдельно сценарии много соединений.
