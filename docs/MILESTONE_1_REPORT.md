# Milestone 1 report

Status: complete  
Reasoning effort: High  
Runtime boundary: local read-only preview only

## Delivered

- loopback-only ASP.NET Core controller;
- English dashboard with explicit server/readiness lock;
- catalog projection generated by the existing `ScenarioCatalog.psm1` module;
- search and protocol, family, action and implementation-status filters;
- expandable scenario purpose, prerequisites, evidence contract and known
  defect information;
- sanitized report list and expandable per-scenario explanation/evidence view;
- explicit fixture labeling so mock reports cannot appear to be real results;
- no settings, server, SSH, run, process or network mutation endpoint;
- one dependency-free targeted PowerShell test.

## Dependency decision

The approved architecture requires .NET 10. The official .NET 10 SDK was not
present and was installed before build validation. The project has no external
NuGet package dependency; `ui/NuGet.Config` clears package sources so restore is
deterministic from installed SDK packs.

## Deferred by design

- UI-managed settings and DPAPI secret storage: Milestone 2;
- Debian/Ubuntu SSH provisioning: Milestone 3;
- runner jobs, progress, cancellation and real execution: Milestone 4;
- final human-explanation templates and complete evidence navigation:
  Milestone 5.

The current UI is not a runtime control surface. Disabled buttons communicate
the future workflow without providing a bypass.
