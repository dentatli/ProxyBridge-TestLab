## Повтор вручную

1. Запустить итоговый preview.13 через Start.cmd с UAC; выбрать4.3.0 в «Сборки».
2. В «Тестирование» выбрать сохранённый набор и нажать «Выбрать набор». На другом ПК импортировать JSON, затем при необходимости сохранить его.
3. На странице «Запуск» убедиться, что выбран именно50-сценарный набор, параметры NORMAL/LOW и правильная сборка. Включить разрешение более5min и продолжение только при подтверждённом восстановлении.
4. Нажать запуск и оставить приложение/ПК включёнными. Итоги сохраняются без участия модели.
