## Инструкция для пользователя без открытого чата

Сохранить команды до закрытия приложения. На VM будет отдельный текстовый файл `C:\Users\LabAdmin\Desktop\PB-Redirect-Control-Repeat-20261017.txt`; для действий в WinDbg сохранить его копию также на физическом ПК.

1. Все точки WinDbg должны оставаться отключёнными. Если их состояние не подтверждено, проверить на физическом хосте: **Break останавливает всю PB-BUILD-W11-25H2, включая Codex и RDP.** При активном kd> повторный Break не нужен. Ввести `bl`, затем всегда отдельной командой `g`, даже при ошибке. Ожидаются прежние семь IDs0..6, все d. При отличии не выполнять Run/не включать точки/не загружать stage; сохранить вывод и вернуться в чат. Точки во время всего опыта отключены. Logopen не требуется.
2. Штатно закрыть приложение GPT/Codex в VM, сохранив работу. Закрытие приложения не гарантирует освобождения всех связанных процессов; неизвестные процессы не завершать. Не оставлять параллельных тестов/разработческих запусков.
3. В административном PowerShell внутри VM проверить свободную память:

```powershell
Get-CimInstance Win32_OperatingSystem | Select-Object @{Name='FreeGiB';Expression={[math]::Round($_.FreePhysicalMemory/1MB,2)}}
```

Нужен заметный запас выше2ГиБ, желательно около3ГиБ перед запуском. Это рекомендация запаса для helpers/CLI, исходный cohort gate остаётся2ГиБ. Если свободно2ГиБ или меньше, не запускать; сохранить показание для чата. При промежуточном запасе wrapper всё равно заново проверяет фактическую память каждой фазы. Не обходить ошибки/не менять порог/конфигурацию VM.
