При превышении срока завершается только этот worker, результат помечается недоступным/неуспешным без выдуманных flows или байтов. Core между сценариями не перезапускается. Переход далее по-прежнему разрешён только после подтверждения изоляции. Ресурсы нагрузки измеряются у действительного дочернего worker.
