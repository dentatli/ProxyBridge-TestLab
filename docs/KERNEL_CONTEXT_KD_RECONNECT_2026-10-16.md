## Подготовить на физическом хосте

Сохранить эту страницу и команды до Break. Убедиться, что на общей VM не идёт согласованный runtime другого чата; при активном прогоне Break отложить до его завершения. Агент в WinDbg не действует, нагрузку не запускает.

**Break останавливает всю PB-BUILD-W11-25H2, включая Codex и RDP.** Если WinDbg уже стоит на активном kd>, новый Break не нужен. Каждую команду вводить отдельно, Enter после каждой; весь список блоком не вставлять. Не добавлять `; g` к другой команде.

После одного USER Break:

1. `.logopen /t C:\Users\Administrator\pb-kd-reconnect-inventory-20261016.log`
2. `bl`
3. `.expr`
4. `.bpcmds`
5. `lmvm nt`
6. `lmvm tcpip`
7. `lmvm fwpkclnt`
8. `.logclose`
9. `g`

Последний g всегда отдельный, даже при ошибке чтения/символов/логирования. Если logopen не сработал, сохранить console вручную; после оставшихся read-only команд ввести g отдельно. При ошибке другой команды не чинить symbols/offsets на остановленной VM: сохранить сообщение, logclose и g отдельно. Если неожиданная остановка повторится, сохранить её сообщение и g отдельно; не начинать workload.

Ничего не регистрировать, не включать, не удалять и не подгружать stage/patch. В этом read-only шаге не выполнять bd по прежним IDs вслепую: состав и принадлежность нынешних точек ещё не проверены. При непустом bl сохранить весь список и тела; не трогать чужие точки. Команда [lm с verbose output](https://learn.microsoft.com/en-us/windows-hardware/drivers/debuggercmds/lm--list-loaded-modules-) показывает в том числе headers/версии и состояние symbols; если поля недоступны, это ограничение данных, не доказательство identity match.

После отдельного g передать новый host log. Сначала офлайн проверить inventory, текущие module headers/версии и symbols. Если bl пуст, семиточечный профиль сейчас отсутствует; не пытаться включить прежние IDs. Если есть точки, сопоставить их адреса и тела с нынешними модулями. Затем отдельно выбрать следующий read-only code/symbol gate. Старый [план семи точек](KERNEL_CONTEXT_PACKET_MINIMAL_V1.md) сохраняется как неподтверждённый проект; для его установки/исполнения потребуются актуальная проверка и новый комплект, а не Run старого 163607.
